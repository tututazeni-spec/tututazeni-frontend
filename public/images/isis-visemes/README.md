# Visemas da Ísis (12 imagens)

Mesmas dimensões e enquadramento de `../isis-avatar.png` (1024×1024, rosto e
corpo na mesma posição — só a boca muda). Ficheiros PNG com estes nomes:

| Ficheiro | Pose da boca | Sons |
|---|---|---|
| `rest.png` | fechada, em repouso | silêncio, pausas (opcional: usa-se `isis-avatar.png`) |
| `mbp.png` | lábios fechados e premidos | m, b, p |
| `fv.png` | dentes de cima no lábio de baixo | f, v |
| `a.png` | aberta, grande | a |
| `e.png` | meio aberta, esticada | e, é, c, k, q, g |
| `i.png` | esticada, dentes quase juntos | i, s, z, t, d, n, l |
| `o.png` | arredondada, média | o, ó |
| `u.png` | arredondada, pequena e projetada | u |
| `chj.png` | lábios projectados, dentes visíveis | ch, j, x |
| `r.png` | boca entreaberta, língua levantada | r, rr |
| `ao.png` | arredondada, dentes visíveis | ã, õ, ão, ou |
| `lhnh.png` | língua contra o palato/dentes | lh, nh |

Enquanto faltar um ficheiro, essa pose usa `isis-avatar.png` (fechada) ou
`isis-avatar-mouth-open.png` (aberta). Mapeamento texto → visema: `components/ai-tutor/visemes.ts`.
